## 📌 Sobre

Este projeto foi desenvolvido durante a **Imersão Front-End com IA da Alura**, com o objetivo de aprender fundamentos do desenvolvimento web utilizando HTML, CSS e JavaScript, além de explorar o uso de Inteligência Artificial como apoio no desenvolvimento de código.

Durante o projeto, foi criado um clone simplificado da interface da Netflix, permitindo que o usuário selecione um perfil e navegue por um catálogo de conteúdos.

A aplicação utiliza HTML semântico para estruturação da página, CSS para estilização e responsividade, e JavaScript para manipulação do DOM e criação de funcionalidades dinâmicas.

Além disso, o projeto utiliza **Local Storage** para armazenar informações do usuário entre diferentes páginas da aplicação.

---

## ⚙️ Funcionalidades
- Seleção de perfis de usuário
- Navegação entre páginas
- Catálogo dinâmico de conteúdos
- Armazenamento de informações utilizando Local Storage
- Interface inspirada em plataformas de streaming
- Layout responsivo
- Interatividade com JavaScript

---

## 🧠 Conceitos Fundamentais Praticados
Durante o desenvolvimento do projeto, foram trabalhados diversos conceitos importantes de desenvolvimento front-end, como:
- Estruturação de páginas com HTML5
- Uso de HTML semântico para organização e acessibilidade
- Organização de conteúdo utilizando listas, imagens e componentes visuais
- Estilização com CSS, incluindo seletores, posicionamento e efeitos hover
- Criação de layouts inspirados em plataformas de streaming
- Responsividade para diferentes tamanhos de tela
- Manipulação do DOM com JavaScript
- Uso do Local Storage para persistência de dados
- Organização de código em módulos JavaScript
- Estruturação de dados para renderização dinâmica do catálogo
