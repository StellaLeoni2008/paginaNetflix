## 📌 Sobre
Este projeto foi desenvolvido durante a Imersão Front-End com IA da Alura, com o objetivo de aprender os fundamentos do desenvolvimento web utilizando HTML, CSS e JavaScript, além de explorar o uso de Inteligência Artificial como apoio no desenvolvimento de código.

Durante as aulas, foi criado um clone simplificado da interface da Netflix, no qual o usuário pode selecionar um perfil e acessar um catálogo de conteúdos. O projeto utiliza HTML semântico para estruturar a página, CSS para estilização e responsividade, e JavaScript para adicionar interatividade e manipulação do DOM.

## 🧠 Conceitos Fundamentais Praticados
Durante o desenvolvimento do projeto, foram trabalhados diversos conceitos importantes de desenvolvimento front-end, como:
- Estruturação de páginas com HTML5
- Uso de HTML semântico para melhorar organização e acessibilidade
- Organização de conteúdo utilizando tags, listas e imagens
- Estilização com CSS, incluindo seletores, classes e efeitos hover
- Criação de layouts modernos inspirados em plataformas de streaming
- Responsividade para diferentes tamanhos de tela
- Manipulação do DOM com JavaScript
- Uso do Local Storage para salvar informações do usuário entre páginas
- Organização de código em módulos JavaScript
- Estruturação de dados para gerar conteúdo dinâmico no catálogo
